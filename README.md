## Основной проект — Production SRE Lab

Личный инфраструктурный стенд в **MWS Cloud**, на котором я отрабатываю задачи, близкие к повседневной работе SRE/DevOps-инженера.

**Что реализовано:**

- Развёртывание виртуальных машин и сетевой инфраструктуры с помощью Terraform; использование удалённого состояния.
- Автоматизация настройки серверов и развёртывания приложения через Ansible.
- Контейнеризированный стек **FastAPI + PostgreSQL** на Docker Compose.
- Автоматизированные тесты приложения с **pytest**.
- CI-пайплайн на **GitHub Actions**: тесты, интеграционная проверка с PostgreSQL, сборка Docker-образа и публикация в **GHCR**.

**Следующие задачи:** развёртывание версий приложения через CI/CD, метрики, мониторинг, алертинг и тренировка реакции на отказы.

> Репозиторий проекта пока закрыт: готовлю безопасную публичную версию без ключей доступа и конфиденциальных конфигураций.
